# 系统拆解：他的完整打法与一段关系的生命周期

> 单看话术是碎片，把他做的所有事放在一起，才能看到一套完整系统。
> 看懂全局，你才知道该在哪个环节设防。

**前三个模块是能力，最后一层是诈骗。**
多数人只看到前三层（"他好会撩"），**识别的关键在最后一层**——它藏不住，只是没人告诉你要去看。

## 模块一：流量入口

他的获客完全靠**内容**，不靠主动追：

| 渠道 | 内容 | 作用 |
|---|---|---|
| 抖音 | 健身展示、日常、暧昧特效 | 被动获客 |
| 朋友圈 | 健身照、生日收款晒图、分组官宣 | 持续经营 |
| 线下 | 校内、酒吧街、网吧搭讪 | 主动出击 |

**关键**：他搭讪时从来不是陌生人——对方加他之前已经看过他的内容。**聊天只是最后一步转化。**

> 识别点：一个聊天能力极强、且内容经营得很稳定的人，他的"会撩"是系统性的，不是天生的。

## 模块二：聊天转化——标准流水线

把他的对话按时间排列，能看到一条流水线：

```
第1天   开场接梗 → 要联系方式（撒娇索取连招）
第1周内 互称宝宝 + 共同梗 + 每晚固定聊天时段
第2周   报备制度 + 深夜真心话 + 角色扮演（服从性测试）
第3周   共同仪式（存钱/约会日）+ 表决心公式
第4周   关系既成事实（但口头不确认）
```

**最关键的一句话：他从不主动确认关系，但每一步都在加深绑定。**

- 口头不确认 = 给自己留退路
- 行为全绑定 = 让你产生"我们已经在谈了"的错觉

> 识别点：**推进了所有该推进的，唯独不给你一个名分。** 你提确认，他就"顺其自然"。

## 模块三：关系维护——低成本高频率

| 动作 | 他的成本 | 效果 |
|---|---|---|
| 主动报备 | 极低 | 让你习惯他的存在 |
| 每晚固定聊天 | 低 | 养成依赖 |
| 固定约会日 | 中 | 稀缺感 + 确定性 |
| 共同存钱 | 低（他出少） | 你的沉没成本 |
| 撒娇/委屈 | 零 | 情绪价值 |
| 生日收款晒图 | 负成本（还赚钱） | 社交货币 + 收益 |

**每一个动作都是低成本高收益的投资。** 他不是在投入感情，他是在做投入产出比。

> 识别点：数一数这段关系里谁投入得多。**仪式是共同的，成本是你的。**

## 模块四：风险对冲层（最该看的一层）

这一层是他系统里唯一不属于"真诚社交"的部分：

| 机制 | 做法 | 你怎么发现 |
|---|---|---|
| 人物代号化 | 给不同人讲不同版本 | 他的故事在不同场合细节不一致 |
| 版本话术 | 同一件事，给A说版本一，给B说版本二 | 和共同朋友对一下就露馅 |
| 官宣管理 | 朋友圈分组可见，只对部分人公开 | 让共同朋友看他的朋友圈 |
| 记录清理 | 出事后删互动记录 | 突然消失的点赞和评论 |
| 小额拒收 | 18块不要，500照收 | 回忆一下：拒的都是小额吗 |
| 时间块管理 | 周五回家、周二约会、深夜分配 | 他的时间块规律到反常 |
| 危机公关 | 倒打一耙→假性认错→技术否认→甩锅→装傻 | 见红旗清单 14 条 |

**这一层的每一个细节，都能被验证。这是他系统里最脆弱的部分。**

## 一段关系的完整生命周期

从他被完整记录的三个月，还原标准节奏：

```
第1月  升温期
       接梗→暧昧→互称宝宝→报备→"认认真真谈恋爱"
       他的目标：让你习惯他的存在

第2月  绑定期
       共同仪式→约会日→见朋友→介绍给朋友
       他的目标：进入你的生活圈

第3月  维持期
       低频维护 + 偶尔惊喜 + 出问题用小作文
       他的目标：稳定但不冷淡
```

**这个节奏本身是健康的**——问题在于他同时跑了不止一条这样的流水线，而且每条线都在用第1月的强度对待新的人。

> 识别点：如果你感觉"我们进展很快但总觉得哪里不对"，通常是你在第2月，而他在别人的第1月。

## 三个数字（他的系统特征）

- **n ≥ 3**：他身边同时存在的关系数量从不低于 3
- **半个月**：从上一段冷淡到下一段热恋的过渡期
- **48小时**：一份曝光内容发布后，联系到当事人的受害者数量

**规模本身就是证据。** 一个人的精力是有限的，能同时维持这么多高强度关系，说明有一套系统在支撑——而不是"他真的很受欢迎"。

## 如果你正在这段关系里

按这个顺序自查：

1. 他有没有说过"我们是什么关系"？——没说过就是答案
2. 他的朋友圈，你和别人看到的是同一版吗？
3. 你提出质疑时，他的反应是解释还是让你别问？
4. 这段关系里，谁投入得更多？
5. 他说的关于自己的事，你能旁证几条？

**五条里有两条答不上来，就该认真考虑了。**

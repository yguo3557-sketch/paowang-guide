# 话术关键词库：可直接搜索的话术指纹

> 拿到聊天记录，先用这张表做**初筛**——搜这些词/句式，命中的地方重点看。
> 命中不等于定罪，只是标记"这里值得看一眼"。

## 怎么用

1. 把聊天记录导出成文本
2. 按下面的分组逐组搜索关键词
3. 命中的句子标出来 → 回到 `红旗清单.md` 查该模式的详细识别方法
4. 也可以直接跑仓库里的 `scan.py` 自动扫

## 1 纯情宣言型
```
我只谈恋爱    不玩暧昧    我很挑的    不是谁都聊
我是认真的    我不随便    我不是那种人
```
> 注意：这些话**本身没问题**。问题是说完后行为是否跟上。

## 2 前任切割型
```
断干净了    早就不联系    不会复合    分了很久了
她是我过去    别提她了    都过去了
```
> 配套检查：说完这些话，社交平台还有没有互动。

## 3 人设三件套型
```
我爸妈管得严    家里管得死    要报备    周末要回家
我爸的（车/公司）    家里有（房/钱）    生活费    被罚
中考/高考多少分    我学习很好    年级前
```
> 三件套**同时命中**才是信号。单项命中很正常。

## 4 接梗飞快型
```
（无特定关键词，看行为）
```
> 检查方式：数一数对话里有没有他接不住的话。一次没有 = 异常。
> 或者看：他是不是对谁都情绪价值拉满。

## 5 撒娇索取连招型
```
留一个嘛    X一个嘛    想要嘛    好不好    行不行嘛
哎哟喂    真的是    一点面子不给    你好拽
```
> 形态：索取 → 被拒 → 委屈 → 调侃 → 再撒娇。**看这四步是不是连着出现。**

## 6 主动报备型
```
到健身房了    在吃饭    到家了    回学校了
[照片]    [定位]    我到啦    刚到
```
> 检查：内容是不是永远这三样？时间是不是规律到反常？

## 7 固定约会日型
```
每周X    固定    这周不行    老规矩    下次吧
家里有事    这周末回不去    临时有安排
```
> 检查：是不是**每周只有一天**能见你？

## 8 深夜真心话型
```
真心话    大冒险    你先问    说实话    走心
深夜（23:00后的长聊）    睡不着    聊会儿
```

## 9 共同仪式型
```
一起存钱    小荷包    我们的（基金/账户）    每天存
打卡    一起追    我们的歌    专属
```

## 10 例外感型
```
你和别人不一样    你是例外    你跟她们不同
我一般不这样    只有你能让我
```
> 追问一句"具体哪里不一样"——答不上来就是话术。

## 11 小作文道歉型
```
（长文本特征）
我知道你现在    我们能不能    再给我一次
我会改    我认真的    我和爸妈说了
其实我    但是我想说
```
> 特征：300字以上、结构完整、八步齐全。**真心道歉是乱的，套路道歉是顺的。**

## 12 经济暗示型
```
手头紧    最近没钱    生活费还没到    这个月有点
好好看    我该收下的    我这个坏了    正好和这个一样
```
> 检查：说完这些，你有没有主动掏钱？

## 13 不确认关系型
```
顺其自然    我们先这样    不着急    慢慢来
不用定义    感觉对了就行    你知道的
```
> **这是整套系统的核心开关。** 命中 + 行为全绑定 = 最危险的组合。

## 14 被抓包话术链型（重点）
```
我记得你不是说…    那你呢    你不也…
我会改一点的    虽然也不知道能不能    我试试
我没有喝    我没做    不是你想的那样
他去的    我兄弟    是他们
？    ？ ？    什么什么    爱是什么是什么
```
> **五连招顺序**：倒打一耙 → 假性认错 → 技术否认 → 甩锅 → 装傻。
> 命中任意两招就该警惕，五招齐全基本确认。

## 15 欲拒还迎收钱型
```
不敢领    无功不受禄    这不合适    你这是干嘛
那我收了    下次请你    算我借的
```
> 检查：说完"不敢领"，转账是不是"已收款"？

## 16 小额拒收型
```
这个不要    别转了    十几块就算了
（对比：大额秒收）
```
> 检查：拒收的都是小额吗？收下的都是大额吗？

## 17 服从性测试型
```
叫我主人    叫爸爸    叫哥哥    喊一声
下次语音叫    发语音    开语音
听话    乖    叫一声
```

## 18 占有欲玩笑型
```
我的人    不允许    我的小三    你别去
（对比：他自己想去就去）
```
> **关键看双标**：他说完"你是我的人"，转头自己出去玩。

## 组合信号（比单项更准）

| 组合 | 含义 |
|---|---|
| 13 + 6 | 不确认关系，但天天报备 —— 绑定你但不给你名分 |
| 7 + 14 | 时间块管理 + 完整危机话术 —— 老手 |
| 3 + 12 | 家里有钱 + 反复说手头紧 —— 人设与行为矛盾 |
| 10 + 11 | 例外感 + 小作文 —— 标准的安抚流水线 |
| 17 + 18 | 服从性测试 + 占有欲 —— 控制型关系的前兆 |
| 5 + 15 | 撒娇索取 + 欲拒还迎收钱 —— 情感与金钱双线索取 |

## 反向信号（这些出现，可以降低怀疑）

也别草木皆兵。这些信号说明他可能是真诚的：

- 主动把你介绍给朋友和家人
- 你提质疑时，他直接给证据而不是转移话题
- 关系确认是他主动提的
- 时间不规律但解释合理，且能被验证
- 他投入的钱和时间不少于你
- 他的故事在不同场合版本一致

**检测的目的不是抓坏人，是搞清楚你在跟谁相处。**

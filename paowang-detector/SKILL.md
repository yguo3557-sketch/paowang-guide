# 炮王识别指南

> **这是一份反面案例拆解。**
>
> 素材来自一个人被完整记录的真实案例：他的聊天记录、朋友圈内容、时间线、多位当事人的交叉证词。
> 我们把他做的每一件事、说的每一句话拆开来看——**不是为了教你学他，是为了让你一眼认出他。**
>
> 这套系统能在三个月内同时维持三段以上关系而不翻车，靠的不是运气，是方法。
> 方法被拆解之后，就不再神秘。

## 使用前先记住三条

1. **看行为，不看宣言**。"我只谈恋爱不玩暧昧"是宣言，深夜失联、拒绝公开、进度错配是行为。
2. **看一致性，不看强度**。承诺越猛烈越要打折。一致的行为重复一百次，胜过一句"我要认真"。
3. **看敢不敢被验证**。真人设不怕你问。**任何让你"不好意思再问下去"的反应，本身就是红旗。**

## 他的系统长什么样

拆开来看，一共四个模块加一层对冲：

```
┌──────────────────────────────────┐
│  人设中枢：学霸 / 家教严 / 家里有钱  │
│  + 健身视觉 + 纯情小男孩            │
└───────────────┬──────────────────┘
                │
   ┌────────────┼────────────┐
   ▼            ▼            ▼
流量入口      聊天转化       关系维护
抖音/pyq      接梗/撒娇      报备/仪式
健身展示      连招/小作文     约会日
                            官宣管理
   └────────────┼────────────┘

  代号化 / 版本话术 / 删记录
  分组官宣 / 小额拒收 / 时间块管理
```

**前三个模块是能力，最后一层是诈骗。** 识别的关键在最后一层——它藏不住，只是没人告诉你去看。

## 识别框架：六步

```
第一步  对照话术   —— 他说的这句话，属于哪个已知套路？
第二步  找红旗     —— 这个套路通常伴随什么信号？
第三步  做验证     —— 用一个低成本的验证动作试他
第四步  看反应     —— 他是坦然对答，还是转移话题/发脾气/委屈？
第五步  反制       —— 用一句话拿回主动权
第六步  决定       —— 继续观察 / 降级 / 退出
```

## 反应识别：他被质疑后的四种应对（全是红旗）

被验证或质疑时，他的第一套话术会切换成第二套：

1. **转移话题**："我在吃饭"——不接你的问题，抛一个日常
2. **内疚反转**："你查我？你不信任我"——把"他的行为"变成"你的态度问题"
3. **委屈装弱**："每次都让我小嘴巴闭好🥺"——让你自我反省
4. **发脾气**：突然暴躁，让你因为怕吵架而闭嘴

**四条全是红旗。** 真诚的人被质疑时的反应是：解释 + 提供证据。套路者被质疑时的反应是：让你不再问。

## 验证动作库（低成本，直接用）

- **突击邀约**：在非约定时间发起见面，看反应
- **版本核对**：把他跟你讲的某件事，和共同朋友讲的版本对一下
- **社交留痕**：看他在社交平台和你之外的互动（频率、称呼、时间线）
- **时间线复盘**：把他说"在家"的日期，和他动态里的定位对一下
- **具体追问**：对人设细节追问（哪个健身房？家里哪个小区？），看是否含糊
- **安全底线**：直接要近期健康报告。**不给=没有，没有例外**

## 反制话术（十句，直接用）

| 场景 | 你可以说的话 |
|---|---|
| 被质疑"不信任" | 信任是做出来的，不是要出来的。 |
| 他回避问题 | 你没回答我的问题，回到刚才那件事。 |
| 被撒娇索取 | 我很喜欢你，但这件事我不答应。 |
| 被催推进亲密 | 我不需要先证明什么。 |
| 拒绝安全措施 | 没有报告就不继续，没得商量。 |
| 被借钱/暗示 | 我不借钱给关系不确定的人。 |
| 被发现说谎 | 你跟我说的是A，跟别人说的是B，解释一下。 |
| 被冷处理 | 你三天没回，我默认这件事结束了。 |
| 想确认关系 | 我们现在是什么关系？请明确说。 |
| 决定离开 | 不用解释，不用吵，删了就行。 |

## 使用方式

```
帮我分析这段聊天记录，他是真心的吗
他说"……"，这是什么套路
我该怎么回他这句话
帮我复盘这段关系，时间线是……
```

把聊天记录或原话给我，我会对照红旗清单逐条拆。**我不会替他找借口，但也不会无端定罪——一切以行为和证据为准。**

## 边界

- 本 skill 用于**自我保护与识别**，不用于报复、网暴、人肉
- 拆解的是**行为模式**，不是性别（"男的都……"这种话不在这里）
- 涉及人身安全、财产损失、健康风险，优先报警或求助专业人士

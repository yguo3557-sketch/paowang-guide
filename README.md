# 炮王识别指南

一份完整的**反面案例拆解**。

素材来自一个人被完整记录的真实案例：聊天记录、朋友圈内容、时间线、多位当事人的交叉证词。
我们把他做的每一件事、说的每一句话拆开来看——**不是为了学他，是为了让你一眼认出他。**

每一处话术都标注了：**他在干嘛 → 识别信号 → 你怎么接**

## 目录结构

仓库分两大板块：**人物拆解**（看懂这个人）+ **检测工具**（拿去用）。

```
paowang-detector/
├── SKILL.md                 # 炮王识别指南：系统图 + 18模式 + 验证动作 + 反制话术
│
├── 人物拆解/                 # ← 拆解这个人
│   ├── 话术拆解.md           # 13个聊天原话案例，每句标「他在干嘛/识别信号/你怎么接」+ 金句指纹表
│   ├── 人设拆解.md           # 人设三件套 / 朋友圈内容日历 / 报备与仪式，每步标识别点
│   └── 系统拆解.md           # 四个模块 + 对冲层 + 关系生命周期 + 三个数字
│
├── 检测工具/                 # ← 拿去用
│   ├── 聊天检测SOP.md        # ★ 主入口：八步流程 + 18项评分卡 + 报告模板
│   ├── 话术关键词库.md        # 可直接搜索的18组话术指纹 + 组合信号 + 反向信号
│   └── 红旗清单.md           # 18个模式逐一展开 + 通用决策树
│
├── scan.py                  # 命令行扫描器
└── examples/
    └── demo_chat.txt        # 虚构演示样本，可直接跑来看效果
```

**建议顺序**：先拆人（话术 → 人设 → 系统），再用工具（SOP → 关键词库 → 红旗清单）

## 怎么用聊天记录做检测

两种用法：

**① 让 AI 帮你分析**（推荐）——把聊天记录贴给 AI，它会走完八步流程，出一份检测报告：
```
帮我分析这段聊天记录，他是真心的吗
```

**② 用脚本先扫一遍**——快速初筛，看命中哪些模式：
```bash
python paowang-detector/scan.py chat.txt -v
```
输出示例：
```
检测结果：🟠 高度可疑   总分 28.0
命中模式：
  · 14 被抓包话术链   命中4次   加权分 6.0
  · 3 人设三件套     命中3次   加权分 4.0
  · 13 不确认关系    命中2次   加权分 4.0
⚠ 组合信号：控制型前兆 / 情感金钱双索取
```

脚本只做关键词初筛，支持 `--json` 输出。**最终判断请走完 SOP 八步。**

### 风险等级

| 总分 | 等级 | 建议 |
|---|---|---|
| 0-8 | 🟢 低风险 | 正常相处，保持观察 |
| 9-18 | 🟡 需观察 | 做 2-3 个验证动作再判断 |
| 19-30 | 🟠 高度可疑 | 严肃谈话 + 要求明确关系 |
| 31+ | 🔴 基本确认 | 建议退出，先保护好自己 |

## 三条判断原则

1. **看行为，不看宣言** —— "我只谈恋爱"是宣言，失联和拒绝公开是行为
2. **看一致性，不看强度** —— 承诺越猛烈越要打折
3. **看敢不敢被验证** —— **任何让你"不好意思再问下去"的反应，本身就是红旗**

## 安装

**Codex**（默认）：

```bash
# 一键
bash <(curl -fsSL https://raw.githubusercontent.com/yguo3557-sketch/paowang-guide/main/install.sh)

# 或手动
cp -r paowang-detector ~/.codex/skills/
```

**Claude Code**：把 `~/.codex/skills/` 换成 `~/.claude/skills/`，或用 `install.sh --claude`。
Windows 用户可用 `install.ps1`。

也可以不安装，直接把 `SKILL.md` 贴进对话当 prompt。

## 最后一句话

**他不说假话，他只说真话里对你最有利的那一半。**

这就是为什么他难被拆穿，也是为什么——你要看行为，不要听句子。

## 边界

- 本仓库用于**自我保护与识别**，不用于报复、网暴、人肉
- 拆解的是行为模式，不是性别（"男的都……"这种话不在这里）
- 涉及人身安全、财产损失、健康风险，优先报警或求助专业人士
- 素材已脱敏，不指向任何真实个人
